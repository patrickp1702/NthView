A kaleidoscope for learning

NthView

Learn anything, in the nth view that suits you. The same content, turned, appears in a new form: a game, a scenario, a quiz. One concept, many dimensions, one view at a time.

The views

    1Pick a view

    Choose the dimension that fits how you learn, or open a ready-made doc or lesson.

    2Hand over the content

    A topic, a paper, pasted notes or code. The agent turns it into that view's data and checks it.

    3Open one file

    You get a single HTML file that runs on its own. Want another angle? Ask for another view.

    See AGENTS.md for how views are built.
