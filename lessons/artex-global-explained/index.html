Glossary

Agent ch. 2
A program that uses a language model to decide its next action, acts with tools, reads the result and goes again.
Approval gate ch. 3
A point where a risky action waits for the human operator to say yes.
Authorized scope ch. 3
The systems the test is allowed to touch; anything else is off limits however interesting.
Exploration graph ch. 2
The team's shared memory of what has been found and tried, so no agent repeats work or forgets a lead.
Fact ch. 2
Something a worker observed and recorded, with evidence, in the shared memory.
Finding ch. 2
A confirmed security weakness, built from facts, that goes into the report.
Planner ch. 2
The agent that turns goals into work orders for the workers and keeps the to-do list.
Work order ch. 2
One concrete intent handed to a worker: what to try, against what, and what counts as done.
